TABLETOP LEDGER — PWA HOSTING PACKAGE

Contents: index.html, manifest.webmanifest, sw.js, icons/

For GitHub Pages: upload the contents of this folder (not the ZIP itself) to the root of your tabletop-ledger repository. Then in repository Settings > Pages, set source to Deploy from a branch, branch main, folder /(root), and save. Wait for the Pages URL to become available.

Important: this hosted instance has browser-local storage. Data in your desktop HTML file does not automatically sync to the hosted phone version. Export a JSON backup from the desktop version, then import it into the hosted app after opening it on the phone. Back up regularly. Do not upload your private JSON data into the public GitHub repository.
